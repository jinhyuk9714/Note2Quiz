# Note2Quiz Domain (퀴즈 + 오답노트)

## 목표
- “문제 생성”만이 아니라 **학습을 돕는 오답노트**까지 자동화
- 대학생이 실제로 쓰는 흐름: 강의자료 → 문제풀이 → 오답/복습 → 시험 대비

## 퀴즈 타입(권장)
- 객관식(MCQ): 개념 구분에 좋음
- 단답형: 핵심 키워드 회상
- 빈칸/클로즈(Claze): 문장 기반 암기
- OX: 빠른 점검

## 오답노트에 꼭 넣을 것
- 사용자가 고른 답 / 정답
- 오답 이유(가능하면 1~2문장으로 요약)
- 관련 개념 태그(예: "미분", "가우스 법칙")
- 다음 복습 일정(SRS 기준)

## SRS(Spaced Repetition) 아주 간단한 시작안
- 처음 틀림 → 1일 뒤
- 2번 연속 맞음 → 3일 뒤
- 3번 연속 맞음 → 7일 뒤
(이후는 14, 30...로 확장)

## 생성 결과는 '구조화' 해서 저장
- 문제/정답/해설/태그를 JSON으로 저장하면
  - 재생성 비용 ↓
  - 검증/수정 UX ↑
